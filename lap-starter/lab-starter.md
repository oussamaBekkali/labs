## Introduction

This lab prepares a productive workflow for web and presentation work.

- Use VS Code as the main editor.
- Preview pages and presentations in real time.
- Keep the workspace organized and easy to navigate.

---

<!-- _class: light -->

## Problems Encountered

Common setup issues include:

- Hidden system files are not visible.
- The project README is hard to locate.
- Visual reminders for tasks are missing.
- Web pages and Marp slides cannot be previewed quickly.

---

## Solutions Implemented

The workflow improves clarity and speed:

- Show hidden files in the explorer.
- Keep the README visible in the project tree.
- Use task markers such as TODO and FIXME.
- Install Live Server and Marp preview tools.

---

<!-- _class: light -->

## Tooling overview

- **VS Code**: Main editor for code, files, and terminal access.
- **Live Server**: Launches a local web server with live refresh.
- **Marp for VS Code**: Renders Markdown presentations instantly.
- **Todo Highlight**: Helps identify task markers in the codebase.

---

## Definitions

- **IDE**: An integrated environment for editing, running, and debugging code.
- **Hidden files**: Files such as `.git` and dotfiles, usually hidden by default.
- **Local server**: A local HTTP server that refreshes the browser automatically.
- **Extension**: A plugin that adds functionality to the editor.
