# PHP Concepts Lab

## Why This Lab?

During the previous technical project, we struggled to read and understand error messages. This made it harder to identify problems and handle errors effectively. This lab addresses that challenge by exploring practical PHP concepts that can improve how we understand and structure our code.

## Concepts Covered

### Error and Exception Handling

Learn how to detect errors and exceptions, understand what they indicate, and handle them appropriately.

### Namespaces

Organize classes into clear namespaces and avoid conflicts between classes with the same name.

### Traits

Share reusable code between multiple classes without duplicating behavior.

## Lab Objective

Understand and test each concept through a practical example connected to the technical project.

## Practice Examples

Run the standalone examples in [`practice/`](./practice/) to inspect an
uncaught exception, a missing namespace import, and a class that does not use
its trait. Each intentional error has a matching solution.
