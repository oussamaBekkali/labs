# PHP Error Practice

These standalone exercises complement the PHP concepts in this lab. Each
`error` example intentionally fails; run its matching `solution` to compare.

Run commands from the `lab-php` directory:

```powershell
php .\practice\01-uncaught-exception.php
php .\practice\01-caught-exception.php
php .\practice\02-namespace-error.php
php .\practice\02-namespace-solution.php
php .\practice\03-trait-error.php
php .\practice\03-trait-solution.php
```

The three `error` examples exit with an error on purpose. Read the error type,
message, and file/line before comparing with the corresponding solution.
