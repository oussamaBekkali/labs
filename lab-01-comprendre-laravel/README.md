# Lab 01 : Comprendre Laravel

Ce lab fait partie du cursus d'apprentissage du développement web back-end. Il a pour but de vous faire découvrir et comprendre le framework PHP **Laravel**, son rôle fondamental dans l'industrie, son architecture MVC, ses atouts majeurs et son vaste écosystème.

---

## Informations Générales

- **Numéro du lab** : 01
- **Sujet** : Comprendre Laravel (Rôle, architecture, avantages et cas d'usage)
- **Niveau** : Débutant / Intermédiaire
- **Auteur** : by oussama bekkali
- **Durée estimée** : 2 à 3 heures

---

## Objectifs d'Apprentissage

À la fin de ce lab, vous serez capable de :

1. **Définir** ce qu'est un framework web et expliquer pourquoi Laravel est le framework PHP le plus populaire.
2. **Expliquer** le rôle de Laravel dans le cycle de vie du développement d'applications web modernes.
3. **Comprendre et schématiser** l'architecture **MVC** (Modèle - Vue - Contrôleur) et le cycle d'une requête HTTP dans Laravel.
4. **Identifier** les composants fondamentaux du framework : l'outil CLI **Artisan**, l'ORM **Eloquent**, le moteur de templates **Blade**, le système de **Routing** et les **Migrations**.
5. **Distinguer** Laravel des approches alternatives (PHP natif, CMS comme WordPress, autres frameworks comme Symfony).
6. **Évaluer** les avantages concrets de Laravel en termes de productivité, maintenabilité et sécurité native.
