# Rule: Never Use Emojis

## Directive
- Never use emojis anywhere in the workspace or conversation.
- This applies to:
  - Markdown files (README, documentation, lab guides, notes)
  - Presentations and slide decks (Marp slides, HTML, etc.)
  - Code comments and strings
  - Git commit messages
  - Assistant chat messages and responses

## Alternative Formatting
- Use standard Markdown formatting (bold, italics, headers, lists, blockquotes, tables).
- Use clear descriptive titles, numbered steps, or ASCII indicators instead of emoji icons.
